Basic of Cyber Security

Why is cyber security important?

Because it protects you from:

  • Hacking
  • Password stealing
  • Fake websites
  • virus /malware
  • Data theft
  • Online scams

Password Security

  • Use strong passwords
  • Don't use your name,DOB or simple number
  • Enable two-factor authentication (OTP login)

Network security

Prodects your internet connection from hackers

  • Using firewalls
  • Securing Wi-Fi
  • Avoiding public WI-Fi for important work

Malware protection

Malware = harmful software(virus,worms,trojans)

protection

  • Install antivirus
  • Don't download unknown apps
  • Don't open unknown links/files
